# WowBite Official

A daily news hub built with clean, organized HTML/CSS/JavaScript. Owned & operated by Hyperinversion LTD.

## Structure

```
wowbite-official/
├── index.html          # Main HTML structure
├── css/
│   └── style.css       # Organized stylesheet
├── js/
│   └── script.js       # Organized JavaScript
├── LICENSE             # MIT License
└── README.md           # This file
```

## Features

- 📰 **Multi-section news hub** - Home, News, Trending, Mysteries, Daily Facts, Community, Legal, About
- 🎨 **Dark theme** - Gold & blue accent colors, responsive design
- 🔤 **Font sizing** - Increase/decrease text size for accessibility
- ⭐ **Save favorites** - Users can save their favorite stories
- 🕐 **Live clock** - Real-time date & time display
- 🔐 **GDPR compliant** - Privacy notices & cookie compliance
- 📱 **Mobile friendly** - Fully responsive layout

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Hyperinversionltd/wowbite-official.git
   ```

2. Open in your browser:
   ```bash
   open index.html
   ```

Or deploy to GitHub Pages for live hosting.

## Code Organization

- **index.html** - Clean semantic HTML structure with no inline styles or scripts
- **css/style.css** - All styling with variables, media queries, and hover effects
- **js/script.js** - All functionality with clear comments and functions

## Google AdSense

The site is ready for Google AdSense integration. Add your publisher code in the advertising area on the home page.
